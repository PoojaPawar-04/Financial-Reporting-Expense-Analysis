# 💰 Financial Reporting & Expense Analysis

An interactive financial reporting and expense analysis dashboard built using Python, Pandas, Streamlit, and Plotly.

## 📌 Project Overview

This project analyzes business expenses, budgets, departments, expense categories, vendors, and payment methods.

The dashboard helps users understand spending patterns, compare budgets with actual expenses, identify over-budget areas, and explore financial transactions interactively.

## 🛠️ Technologies Used

- Python
- Pandas
- Streamlit
- Plotly
- Excel

## 📊 Dashboard Features

- 💰 Total Expenses
- 🎯 Total Budget
- 📊 Budget Utilization
- 📈 Budget Variance
- 🔎 Interactive filters
- 📈 Monthly Expense Trend
- 🏢 Department-wise Expense Analysis
- 📂 Expense Category Analysis
- 🎯 Budget vs Actual Expenses
- ⚠️ Over-Budget Department Analysis
- 📂 Expense Category Budget Analysis
- 💳 Payment Method Analysis
- 🥧 Expense Distribution
- 🔥 Department vs Expense Category Heatmap
- 📋 Detailed Expense Transactions
- 📥 Download Filtered Data
